# Chrome Web Store assets

Upload these with the zip from the [latest release](https://github.com/horbel/fluff-meter/releases/latest).
Listing texts and privacy answers are in [docs/chrome-web-store.md](../docs/chrome-web-store.md).
The icon and every PNG in `public/icon` are rendered from [`src/assets/icon.svg`](../src/assets/icon.svg)
(and `icon-16.svg` for 16px) at their exact size.

| File | Size | Where it goes |
| --- | --- | --- |
| `icon-128.png` | 128×128 | Store icon |
| `screenshot-1.png` | 1280×800 | Screenshots: a feed with folded posts |
| `screenshot-2.png` | 1280×800 | Screenshots: fluff vs substance |
| `screenshot-3.png` | 1280×800 | Screenshots: a chip's card, fold posts like this |
| `screenshot-4.png` | 1280×800 | Screenshots: the Fold and Always show rules |
| `screenshot-5.png` | 1280×800 | Screenshots: feed stats |
| `promo-small-440x280.png` | 440×280 | Small promo tile |
| `marquee-1400x560.png` | 1400×560 | Marquee promo tile |

Every person, post, company and number in the screenshots is fictional and the photos are
generated, except the author's own profile card (name, photo, employer) in `screenshot-1.png`.
